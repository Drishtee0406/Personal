This repository contains a collection of my Jupyter notebooks from coursework, experiments, and self-learning.  
It covers **data analysis, machine learning, and database projects**.  

---

## 🔹 Contents  

- **Association.ipynb** – Market Basket Analysis using Association Rules (Apriori, FP-Growth)  
- **Cluster.ipynb / ClusterAnalysis.ipynb** – K-Means & Hierarchical clustering on sample datasets  
- **Decision_Tree.ipynb** – Classification using Decision Tree & visualization of decision paths  
- **ETL_Project.ipynb** – ETL pipeline demonstration with Python + SQL (data extraction & cleaning)  
- **Naive_Bayes.ipynb** – Text classification using Naive Bayes algorithm  
- **Satellite.ipynb** – Remote sensing dataset classification experiment  
- **PersonalProject.ipynb** – Miscellaneous experiments and mini-projects
